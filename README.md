# Study Hive

**Study Hive** is an academic resource-sharing platform built using Django. It allows students to upload, access, and explore subject-specific study materials in a structured and collaborative environment. The goal is to provide an evolving digital library that grows with its user base, supported by intelligent content discovery and a clean, minimal interface.

---

## 🌐 Features

- 📂 Upload and access study materials categorized by subject
- 🔍 Search and explore materials by topic or keyword
- 🧠 Recommendation system (in progress) based on:
  - User preferences
  - Popular materials
  - Recent uploads
  - User activity: downloads, views, and future rating support
- 🪪 Authentication and user profiles
- 📊 (Planned) Activity tracking and resource analytics

---

## 🧰 Tech Stack

- **Backend**: Django
- **Database**: PostgreSQL
- **Frontend**: HTML, CSS, Bootstrap (planned upgrade to Tailwind/React)
- **Deployment**: In development

---

## 🚀 Getting Started

1. **Clone the repository**  
   ```bash
   git clone https://github.com/DrakeRing2099/study-hive.git
   cd study-hive
    ```

2. **Install dependencies**

   ```bash
   pip install -r requirements.txt
   ```

3. **Run the development server**

   ```bash
   python manage.py runserver
   ```
